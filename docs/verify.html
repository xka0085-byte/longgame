Reproduce

git clone https://github.com/xka0085-byte/longgame
cd longgame
node scripts/verify.mjs
node scripts/self-audit.mjs
node scripts/attest.mjs

verify.mjs recomputes published figures from raw data and exits non-zero on any mismatch. self-audit.mjs rebuilds freshness for all lines. attest.mjs rebuilds this page and the hash list.

What is not verified

No third party has independently recomputed the full set. The only two external reviews on record concern mcpreflight scanner results, not these series. If you recompute something and get a different number, open an issue with the command you ran and the output.
