字段定义

  • 企业名：与提交文件、docket 记录中出现的名称保持一致；同一企业不同写法并列保留，不合并。
  • 是否在 docket 出现：只取 是 / 否 / 未核实 三个值。否 的含义限定为「我方扫描范围内未检索到」。
  • 出现日期：docket 记录上的提交日期（YYYY-MM-DD）；无记录时留空，不填检索日期。
  • 来源链接：指向可核对的 CARB 记录页或提交件地址；不得填检索入口页充数。
